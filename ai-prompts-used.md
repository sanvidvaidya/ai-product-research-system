# AI Prompts & Workflow Used

This document outlines the structured prompt framework used to conduct AI-driven product research, competitive analysis, and PRD generation.

## 1. Problem Definition Prompt

"Act as a senior product manager. Given the following product idea, identify:
- Target users
- Core problems
- Market opportunity
- Key constraints
- Success criteria"

## 2. Market & Competitor Analysis Prompt

"Act as a market research analyst. Analyze the competitive landscape for this product category in India. Provide:
- Major competitors
- Their strengths and weaknesses
- Differentiation opportunities
- Pricing models
- Go-to-market strategies"

## 3. User Persona Generation Prompt

"Create detailed user personas for this product, including:
- Demographics
- Goals
- Pain points
- Behavior patterns
- Technology usage"

## 4. Feature Prioritization Prompt

"Act as a product strategist. Propose and prioritize features using impact vs effort logic. Highlight:
- Must-have features
- Differentiators
- Future enhancements"

## 5. PRD Drafting Prompt

"Generate a structured Product Requirements Document including:
- Problem statement
- Objectives
- Scope
- User stories
- Acceptance criteria
- Success metrics
- Risks and dependencies"

## 6. Decision Support Prompt

"Based on the analysis above, recommend whether to build, pivot, or abandon the product idea. Provide justification using market and user insights."

---

## Workflow Summary

The process simulates how an AI-first Product Manager or Business Analyst accelerates research, planning, and decision-making using large language models.
